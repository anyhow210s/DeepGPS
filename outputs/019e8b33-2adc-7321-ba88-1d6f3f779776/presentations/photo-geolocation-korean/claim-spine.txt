Thesis: EXIF GPS 없이도 사진의 시각적 특징만으로 제한된 위치 후보를 예측할 수 있음을 ResNet50 전이학습 파이프라인으로 시연한다.
Audience: 딥러닝 수업 발표 청중, 교수자, 동료 학생.
Arc: 문제 정의 -> 데이터 -> 모델 -> 학습 설정 -> 평가 수치 해석 -> Grad-CAM -> UI 시연 -> 한계와 개선.

Slides:
1. Cover: 로컬 사진만으로 위치를 예측하는 CNN 전이학습 프로젝트.
2. Problem: GPS 메타데이터 없이 이미지 자체의 단서로 위치 카테고리를 분류한다.
3. Dataset: 사용자가 위치별로 수동 분류한 로컬 이미지 폴더를 70/15/15로 분할했다.
4. Pipeline: data -> preprocessing -> ResNet50 -> training -> evaluation -> Streamlit demo.
5. Model: ImageNet pretrained ResNet50의 마지막 분류층을 17개 위치 클래스로 교체했다.
6. Training settings: classifier head 5 epoch 후 layer4 fine-tuning 3 epoch를 수행했다.
7. Results: validation 82.14%, test 74.07%, macro F1 0.68, weighted F1 0.71.
8. Metrics: accuracy/precision/recall/F1/confusion matrix가 각각 무엇을 의미하는지 설명한다.
9. Explainability & demo: Grad-CAM과 Streamlit UI로 예측 결과를 시연한다.
10. Lessons: 클래스 불균형과 작은 테스트 수가 한계이며, 데이터 보강과 모델 비교가 다음 단계다.
